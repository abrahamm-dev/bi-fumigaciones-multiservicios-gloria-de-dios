# bi-fumigaciones-multiservicios-gloria-de-dios
Sistema de Business Intelligence End-to-End para Fumigaciones Multiservicios Gloria de Dios C.A. Diseñado bajo la metodología de Kimball con un stack 100% Open Source (PostgreSQL 13, Pentaho PDI y BA Server) para optimizar el control de inventario de insumos químicos, ingresos y certificados sanitarios.
